## ✦ What is this?

**World of Radhwan** is my personal website — but I didn't want it to feel like a normal portfolio.

It started with one simple goal: **make my own website.**

Then it turned into a whole interactive world with:

- 🎮 Playable mini-games
- 🌍 A website World Map
- ⌨️ An interactive terminal
- 🌎 A visitor community
- ⭐ Visitor reviews
- 🪪 A Visitor Passport
- 🔐 Hidden secrets and easter eggs
- 🎭 Secret themed modes
- 🎵 Music controls
- 🌙 Multiple visual themes
- 💥 Chaotic interactive effects
- ✨ Animations and responsive UI

The visual identity is intentionally **dark, futuristic, neon, glassy and arcade-inspired**.

> **One website. Multiple worlds. A few things you're not supposed to find. 👀**

## 🎮 THE ARCADE

The website includes **six playable mini-games**.

### ⚽ Penalty Shootout Showdown

A football penalty game with two modes:

- Shooter
- Goalkeeper

Goalkeeper mode lets the player choose **Left, Center or Right** to attempt the save.

### ⚡ 10-Second Sprint Dash

Tap as fast as possible to run during a short timed sprint.

### ⚽ Football Juggling Challenge

Keep the ball going and try to beat your score.

### 💄 Makeup Order Routine Challenge

A completely different challenge inside the same arcade — arrange the routine correctly and submit it.

### ⚡ Reaction Rush

A reaction-speed game where the player waits for the signal and reacts as quickly as possible.

### 🧠 Neon Memory Match

A memory-board challenge built into the arcade interface.

## 🌎 COMMUNITY

The site has its own lightweight visitor community powered by **Firebase Realtime Database**.

Visitors can create:

- 💬 Posts
- 📖 Stories
- 🗳️ Polls
- 🎨 Showcases

The community also supports:

- ❤️ Likes
- 💬 Comments
- 🗳️ Poll voting
- 🔥 Feed filters
- 🛡️ Owner moderation

New visitor submissions can remain **pending** until they are approved through the protected owner moderation area.

```text
Visitor
   ↓
Create content
   ↓
Pending
   ↓
Owner moderation
   ├── Approve → Public
   └── Remove
```

The current community intentionally stays **simple and text-based**. There is no image-upload system or Firebase Storage dependency.

## 🔐 FIREBASE SECURITY

Firebase-backed functionality is protected through **Realtime Database Rules** and authentication.

The important security boundary is not simply hiding owner controls in the HTML.

The community moderation flow is designed around:

```text
Public visitor
      ↓
Anonymous visitor session
      ↓
Allowed submission
      ↓
pending
      ↓
Owner authentication
      ↓
Approve / remove
      ↓
approved content becomes public
```

The review owner inbox is also protected so ordinary visitors cannot read the private review data.

> Never put passwords, service-account credentials, private API keys or other secrets into frontend source code.
